# adc-behavioral-model-sva
Real-Number Model (RNM)of an N-Bit ADC in SystemVerilog using Wreal for analog-digital interfacing. Models non-idealities (offset error, gain error, thermal noise, DNL) to emulate realistic analog behaviour at simulation - efficient runtime. Includes a self-checking testbench with directed, ramp, and randomized stimulus, a scoreboard comparing.
